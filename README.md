# Projeto de Texto

## Descrição

Este projeto tem como objetivo apresentar um site simples e organizado com o tema "Projeto de Texto". A estrutura foi criada para facilitar a leitura e a apresentação do conteúdo de forma clara e visualmente agradável.

## Objetivo

Demonstrar um exemplo de página web com foco em texto, organização visual e uso básico de HTML.

## Tecnologias utilizadas

- HTML
- CSS
- JavaScript

## Estrutura do projeto

- `index.html` — arquivo principal da página
- `README.md` — documentação do projeto

## Como executar

1. Abra o arquivo `index.html` em um navegador.
2. Se preferir, utilize um servidor local para visualizar a página com mais praticidade.

## Autor

Projeto desenvolvido com foco em aprendizado e apresentação de conteúdo textual.
